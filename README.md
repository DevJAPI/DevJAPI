### 👨‍💻 About Me

I'm a Colombian software developer focused on **Full-Stack** and **Mobile** engineering. I specialize in turning ideas into reliable digital products, balancing solid backend architecture with clean, intuitive user interfaces.

- 🚀 **Current Focus:** Building interactive web applications using the **Laravel ecosystem (Livewire, Tailwind, Alpine.js)** and **React / Next.js / TypeScript**.
- 📱 **Mobile Development:** Crafting native and cross-platform mobile apps with **Kotlin** and **React Native**.
- 💡 **Engineering Mindset:** Clean code, scalable architecture, continuous learning, and collaborative technical leadership.
